# Contributing to SmartExpense AI

Thank you for your interest in contributing to SmartExpense AI.

## Getting Started

1. Fork the repository.
2. Clone your fork.

```bash
git clone https://github.com/your-username/SmartExpense-AI.git
```

3. Navigate to the project directory.

```bash
cd SmartExpense-AI
```

4. Install the required dependencies.

```bash
pip install -r requirements.txt
```

5. Run the application.

```bash
streamlit run app.py
```

---

## Development Guidelines

- Follow PEP 8 coding standards.
- Write clean, modular, and well-documented code.
- Keep commits focused on a single change.
- Test new features before submitting.
- Update documentation when appropriate.

---

## Pull Requests

Before opening a pull request:

- Ensure the project runs successfully.
- Verify existing functionality is unaffected.
- Include clear commit messages.
- Reference related issues if applicable.
- Update documentation when necessary.

---

## Reporting Bugs

Please include:

- Operating System
- Python Version
- Streamlit Version
- Steps to reproduce
- Expected behavior
- Actual behavior
- Screenshots (if applicable)

---

## Feature Requests

When suggesting a feature, please describe:

- The problem it solves
- Your proposed solution
- Expected benefits
- Possible alternatives

---

## Questions

If you have questions or need assistance, please open a GitHub Issue.

Thank you for helping improve SmartExpense AI!
