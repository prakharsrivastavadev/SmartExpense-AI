# SmartExpense AI

SmartExpense AI is a Streamlit-powered expense tracking application that helps users monitor spending habits, categorize expenses, visualize financial trends, and make better budgeting decisions.

## Features

- Add and manage daily expenses
- Categorize transactions
- Monthly expense summaries
- Interactive charts and analytics
- Budget tracking
- CSV import and export
- Financial insights dashboard
- Responsive Streamlit interface

## Tech Stack

- Python
- Streamlit
- Pandas
- Plotly
- NumPy

## Installation

```bash
git clone https://github.com/your-username/SmartExpense-AI.git
cd SmartExpense-AI
pip install -r requirements.txt
streamlit run app.py
```
