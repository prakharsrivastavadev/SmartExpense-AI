# SmartExpense AI

SmartExpense AI is an AI-powered personal expense tracking application built with Python and Streamlit. It enables users to record daily expenses, monitor spending habits, analyze financial trends, and make smarter budgeting decisions through interactive dashboards and visual analytics.

## Features

- 📊 Interactive financial dashboard
- 💸 Daily expense tracking
- 🗂 Expense categorization
- 📅 Monthly and yearly spending summaries
- 📈 Spending trend visualization
- 🥧 Expense category distribution charts
- 💰 Budget tracking and monitoring
- 📂 CSV import and export
- 🔍 Expense search and filtering
- 📉 Financial insights and analytics
- ⚡ Fast, responsive Streamlit interface

## Tech Stack

- Python
- Streamlit
- Pandas
- NumPy
- Plotly

## Installation

Clone the repository:

```bash
git clone https://github.com/your-username/SmartExpense-AI.git
```

Navigate to the project directory:

```bash
cd SmartExpense-AI
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Run the application:

```bash
streamlit run app.py
```
